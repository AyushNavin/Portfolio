## Projects

### The Batman Function

A generalized framework for combining multiple functions into a single expression, built around
A1(L, n1, n2, l) (floor, signum and ceiling). Demonstrated with sin(x) then log(x), and applied to the
Batman logo. Raw Batman curves were sourced externally; the framework is my own work.
Full paper: `batman-function-paper.pdf`. Posted on Reddit before joining Scaler — someone posted a
more optimized version within 24 hours.
